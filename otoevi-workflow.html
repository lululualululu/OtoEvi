OtoEvi 实验复现流程

从准备耳内镜数据到生成检查报告，再用固定数据划分和评价协议核对结果。

  1. 准备环境和权重

    按仓库指南安装 PyTorch 与项目依赖，准备 timm 格式的 DINOv3 ViT-S/16 权重，运行单元测试检查环境。

    python -m unittest discover -s tests/unit -v

  2. 准备数据和划分

    每次检查关联一至两张真实视图。OtoInsight 的临床数据尚未公开。复现 IU X-Ray 或 PEIR Gross 时，从授权来源取得数据，并沿用仓库规定的划分和参考文本。

  3. 训练并保存检查点

    选择对应数据集的配置，分别运行种子 42、7 和 3407。冻结的 DINOv3 提取多层特征，解码器结合视觉记忆与视图局部证据生成报告。条款覆盖学习（CCL）在训练阶段对齐报告条款与证据槽。使用第 15 个完整轮次保存的最终检查点。

  4. 仅用图像生成报告

    用 otoevi-predict 加载检查点和真实视图。生成阶段仅使用图像、视图掩码和固定边界标记。

  5. 评估与核对

    用 otoevi-evaluate 对照匹配、错配和空白视图三种条件，汇总语料级 BLEU、ROUGE-L 和 CIDEr。中文报告另核对概念一致性、明确否定及侧别。记录数据划分、配置、种子和运行环境。

    核对仓库已发布的汇总结果时，可运行 python scripts/check_results.py。
